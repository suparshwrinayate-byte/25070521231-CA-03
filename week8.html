Browser APIs

🌐

Fetch API

Fetch API is used to request data from a server or API. It works with Promises and is commonly used to get JSON data.

fetch.js 
fetch("https://jsonplaceholder.typicode.com/users/1")
.then(response => response.json())
.then(data => {
    console.log(data);
})
.catch(error => {
    console.log(error);
});
🌳

DOM Manipulation

DOM allows JavaScript to access and change HTML elements, text, styles and content of a webpage.

dom.js 
let heading =
document.getElementById("heading");

heading.innerText =
"DOM Changed Successfully!";
⚡

Events

Events are actions performed by users such as clicking, typing, hovering or submitting a form.

events.js 
button.addEventListener("click", () => {

    alert("Button clicked!");

});
💾

LocalStorage

LocalStorage allows websites to store data in the browser. The stored data remains even after refreshing the page.

storage.js 
localStorage.setItem(
    "username",
    "Group 61"
);

let name =
localStorage.getItem("username");

What is Fetch API?

Fetch API is a JavaScript interface used to make HTTP requests and retrieve resources from a server.

What is DOM?

DOM stands for Document Object Model. It represents an HTML document as objects that JavaScript can modify.

What are Events?

Events are actions like click, input, mouseover and submit that JavaScript can detect and handle.

What is LocalStorage?

LocalStorage is a browser storage mechanism used to save key-value data without an expiry time.
