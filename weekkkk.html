⚡ Asynchronous JavaScript

Three important ways to handle asynchronous operations.

📞

Callbacks

A callback is a function passed into another function and executed after an operation is completed.

function greet(name, callback){
  console.log("Hello " + name);
  callback();
}

greet("Group 61", function(){
  console.log("Done!");
});
🔗

Promises

A Promise represents the eventual completion or failure of an asynchronous operation.

let promise = new Promise((resolve) => {
  setTimeout(() => {
    resolve("Success!");
  }, 1000);
});

promise.then(result => {
  console.log(result);
});
🚀

Async / Await

Async/Await provides a cleaner and easier way to work with Promises.

async function getData(){
  try {
    let result = await fetch(url);
    console.log(result);
  } catch(error){
    console.log(error);
  }
}

🌐 Browser APIs

JavaScript can communicate directly with the browser.

🌍

Fetch API

Fetch allows JavaScript to request data from servers and APIs.

fetch("https://api.example.com/data")
.then(response => response.json())
.then(data => console.log(data));
🧩

DOM Manipulation

DOM allows JavaScript to change HTML elements dynamically.

document.getElementById("title")
.innerText = "Group 61";
🖱️

Events

Events allow websites to respond to user actions like clicks, typing and mouse movements.

button.addEventListener("click", () => {
  alert("Hello Group 61!");
});
💾

LocalStorage

LocalStorage stores information inside the user's browser.

localStorage.setItem("group","61");
let data = localStorage.getItem("group");

📝 Quick Revision

Perfect for your viva preparation

Callback

A function passed as an argument to another function and executed later.

Promise

An object representing the future result of an asynchronous operation.

Async

Makes a function return a Promise automatically.

Await

Pauses execution inside an async function until a Promise settles.

Fetch

Used to make HTTP requests and retrieve data from APIs.

DOM

The Document Object Model represents the HTML structure of a webpage.

Events

Events detect user actions such as click, input, submit and mouse movement.

LocalStorage

Stores key-value data in the browser and persists even after closing the browser.
