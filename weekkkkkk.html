Core Concepts

01

Callbacks

A callback is a function passed to another function and executed later when a task is completed.

callback.js
function task(callback) {

    setTimeout(() => {

        console.log("Task completed");

        callback();

    }, 1000);
}

task(() => {

    console.log("Callback executed");

});
02

Promises

A Promise represents the eventual completion or failure of an asynchronous operation.

promise.js
let promise =
new Promise((resolve,reject) => {

    setTimeout(() => {

        resolve("Data received");

    },1000);

});

promise.then((result) => {

    console.log(result);

}).catch((error) => {

    console.log(error);

});
03

Async / Await

Async/Await provides a cleaner and easier way to work with Promises.

async.js
async function getData() {

    let result =
        await fetch(url);

    let data =
        await result.json();

    console.log(data);
}

getData();

What is Callback?

A callback is a function passed as an argument to another function and executed after a task is completed.

What is Promise?

A Promise is an object representing the future result of an asynchronous operation.

What is Async/Await?

Async/Await is modern JavaScript syntax used to handle Promises in a simple and readable way.
